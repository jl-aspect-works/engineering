# Security Policy

## Scope

JL Aspect Works Engineering contains shared development-process, architecture, compatibility, and engineering-policy documentation used by JL Aspect Works projects.

Security-sensitive corrections are made on the current `main` branch. This repository does not publish a separately versioned runtime product.

## Reporting a vulnerability

Do not open a public issue when a report would expose a credential, exploit technique, unsafe workflow pattern, or other sensitive information that could put a JL Aspect Works project at risk.

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. If private reporting is unavailable, contact the repository owner privately before disclosing details publicly.

Please include:

- A concise description of the issue.
- The affected document, workflow, example, or commit.
- Reproduction steps when applicable.
- Expected impact.
- Any suggested mitigation.

Security reports are evaluated based on reproducibility and impact. No fixed response-time or disclosure SLA is currently promised.
